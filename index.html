01 · Why it exists

One word in, one word out.

AI tools are good at turning out reports, plans and pages as HTML. They are not as good at getting every sentence right, and when you ask them to fix one line they tend to rewrite twenty.

Fixing it yourself usually means a code editor and a lot of scrolling through markup. Most visual HTML editors are worse: they load the page and write it back out in their own style, so a fix to one word comes back as a file where every line has moved.

VibeRevise only edits the text. Your indentation, comments, entities and attribute quoting are kept exactly as they were, so a diff of the saved file shows the words you changed and nothing else.

02 · Features

What you can do with it

01

Edit on the page

Click any paragraph, heading, list item or table cell and type. Bold, italic, new paragraphs and extra list items work as well.

02

Keep your fixes when the file is regenerated

If another program rewrites the file while you have it open, VibeRevise loads the new version, carries your unsaved edits across and highlights what changed so you can check it.

03

See every change

A list shows each edit, who made it and the exact words that changed. You can undo any one of them and keep the rest.

04

Leave comments in the file

Notes sit in the margin and are saved inside the file as ordinary HTML comments, so they travel with it.

05

Save over the original

In Chrome and Edge, Save writes straight back to the file you opened. A server on your own network can accept saves in place as well.

03 · AI

AI, if you want it

AI is off until you add your own API key for Anthropic, OpenAI, OpenRouter, Google Gemini or a model running on your own computer. You pay the provider directly. With a key added you can ask it to explain a passage, proofread the document, suggest a rewrite or draft a reply to a comment.

Out of the box it can only make suggestions, which you read and then act on yourself. If you switch it to Read and write, its suggestions get an Accept button and nothing changes until you press it. Every change the AI takes part in is listed under the name of the model.

04 · Questions

Questions

Is my document uploaded anywhere?

No. VibeRevise opens and edits the document in your browser, and there is no VibeRevise server to send it to. If you turn on AI, the paragraphs you ask about go to the AI service you picked, and only when you press the button.

Which browsers does it work in?

The web app runs in any current browser. In Chrome or Edge on a computer, Save writes back to the file you opened. Other browsers download the edited copy for you to save yourself.

What can’t it change?

Layout, styles and images are left alone. VibeRevise changes words, and can add paragraphs, lists, tables, bold and italic in the same style as the ones already in the document. Pages that build their text with JavaScript can’t be edited, because the words aren’t in the file.

Do I need AI to use it?

No. All the editing works without it, and AI stays off until you add a key.

Is it free?

Yes, while it’s in beta, with no account and no card. If that ever changes, it will be announced on this page first. AI usage is billed by your AI provider at their prices; VibeRevise adds nothing.
